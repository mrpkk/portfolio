What this demo proves

  • The private key is generated with extractable: false — the browser will never hand it to JavaScript, so page script cannot exfiltrate it.
  • The signature is a real ECDSA P-256 signature over the SHA-256 digest, not a mock.
  • Step 6 is a negative control: one byte of the statement is changed and verification must return false. A demo that only ever prints PASS proves nothing.
  • Everything runs in the browser. Nothing is transmitted — you can verify that in the network tab.
